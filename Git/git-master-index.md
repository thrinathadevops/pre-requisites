## 📋 Command Quick Reference

### Recovery Commands
```bash
git reflog                          # Find lost commits
git reset --hard HEAD@{N}          # Recover to position N
git branch recovery <commit>       # Save lost work
git fsck --lost-found              # Find unreachable objects
```

### Merge & Conflict
```bash
git merge --no-ff feature          # Start merge
git merge --abort                  # Cancel merge
git reset --soft HEAD~1            # Undo commit, keep changes
git checkout --ours file.txt       # Keep our version
```

### Performance
```bash
git clone --depth=1                # Shallow clone
git clone --filter=blob:none       # Partial clone
git gc --aggressive                # Cleanup
git commit-graph write             # Optimize traversal
```

### Inspection
```bash
git status                         # Check state
git diff                          # View changes
git log --oneline --graph         # View history
git reflog                        # View HEAD history
```
